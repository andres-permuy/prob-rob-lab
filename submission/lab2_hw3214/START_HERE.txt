RUN THE CODE
Use the source snapshot as the only copy of these ROS packages in a workspace
with the course dependencies installed. Do not nest it in an existing course
checkout or put two copies of the same packages under workspace/src.

From the configured workspace root, build the supporting packages if this is a
fresh workspace, then build the main Python package:

  colcon build --packages-skip prob_rob_labs
  colcon build --symlink-install --packages-select prob_rob_labs
  source install/setup.bash

Complete demonstration:
  ros2 launch prob_rob_labs turtlebot3_and_door_launch.py run_lab2_controller:=true

Different commanded speed:
  ros2 launch prob_rob_labs turtlebot3_and_door_launch.py run_lab2_controller:=true forward_speed:=0.3

For each repeat, exit the previous launch with Ctrl+C and launch a fresh
simulation. The controller runs once per launch. Gazebo Reset does not restart
the controller or necessarily respawn the dynamically inserted robot.
